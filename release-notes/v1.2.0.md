# Storage Manager 1.2.0

**Please update if you are on 1.1.0:** the entity list in the Database tab (top causes, by integration, all) was missing there. It is back.

The rest closes the points where the other storage tools for Home Assistant were ahead.

- **Who wrote when.** Drag a time range in the effect chart, or pick the last 24 hours or 7 days, and see which entities and events wrote in it, with rows and size.
- **Stored data.** The detail sheet shows the raw rows of an entity, with its attributes and statistics, newest first.
- **Filters and treemap.** Filter the full list by integration, device, usage, where an entity is defined and when it last wrote, then select all matches at once. The groups view starts with a treemap you click into.
- **Safer large changes.** From 25 entities on, you type the number to confirm. A change cut short by a restart shows as *interrupted* in the history.
- **Nightly run for your automations.** It fires `storage_manager_nightly_run` when it is done. Switch it off and start `storage_manager.run_nightly` yourself if you want it at another time.
- **Undo after updates.** A Home Assistant update that changes the database no longer makes older undo files useless.
