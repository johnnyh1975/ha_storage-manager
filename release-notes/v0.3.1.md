## Fixed
- **Sizes on Home Assistant OS.** Its SQLite has no `dbstat`, so the analysis fell back to fixed row sizes and the savings looked far too small for a large database. The estimates are now scaled to the bytes actually in use in the database file. The split between tables stays an estimate; the panel says so.
- **Repack when space is short.** If no repack method fits, the Files tab now explains why with numbers: how much data the file holds, what an ordinary repack and the variant with the temporary copy in RAM need, and how much space you would have to free – or how much data to remove, for example by applying recommendations – for a repack to fit.
- **Layout on wide screens.** The content starts at the left edge like the tabs instead of being centred.

## Why the repack needs that much
A repack writes a compact copy of the remaining data, plus the same amount again through the write-ahead log. With 4 GB of data that is about 8 GB of free space, no matter how large the file is. Once the database has been repacked one time with *Prepare for repacking in small steps*, later repacks need almost no free space.
