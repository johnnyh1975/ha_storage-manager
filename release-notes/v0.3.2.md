## Fixed
- **The safety check asked for far too much space.** It wanted half the database file as working room plus the whole file for a backup – 19.9 GB for a 13.3 GB file, even to purge 37 MB. Deleting rows only writes the touched pages to the write-ahead log and leaves the file the same size. The working room now follows what is deleted (three times its size, at least 512 MB, at most half of the data). The room for a new backup comes from the newest backup with the database; the file size is used only when there is none. The preview shows both parts.
- **Purging outdated rows needs no backup.** These rows are older than your retention and Home Assistant deletes them every night without one. History of deleted entities, orphaned statistics and per-entity purges still get a verified backup first.
