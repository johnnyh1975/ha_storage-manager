# Storage Manager 1.1.0

Three things learned from comparing Storage Manager with the other storage tools for Home Assistant.

- **Long-term statistics by age.** Home Assistant keeps the hourly statistics forever, so they grow every year. In the Settings tab you can now keep them for 6 months up to 7 years, with a separate limit for the energy dashboard (including imported statistics and its cost sensors). The first run shows what goes, runs the safety chain and can be undone; after that the limit is kept every night.
- **Explore folders.** The Files tab shows what takes the space in the config folder and, on Home Assistant OS, in media, share and backup: a ring chart you click through and the largest files below. Read-only.
- **Every dashboard card counts.** A dead entity that is still on a dashboard, in any card or template, is no longer offered for disabling, and the detail sheet lists the dashboards that show an entity.
