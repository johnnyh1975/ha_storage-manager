# Storage Manager 0.4.1

Bug fix release for figures that stayed old after a cleanup.

- **Storage breakdown refreshes after every cleanup.** Home Assistant's Supervisor breakdown is cached for an hour. Until now only deleting backups, files or Docker images cleared that cache, so after repacking the database the bars still showed the old size. Every cleanup clears it now.
- **New analysis after a repack.** The database is measured again once the repack is done, so the size history, the effect chart and the sizes per entity match the smaller file.
- **Readable history.** Changes to the recorder settings show up as "Recorder settings changed" instead of the raw key `action_recorder_changes`, and each cleanup line lists what it covered.

Note: the Supervisor computes its breakdown itself. If its numbers lag right after a cleanup, the refresh button or a new analysis brings them up to date.
