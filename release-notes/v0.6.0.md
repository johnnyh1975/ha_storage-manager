# Storage Manager 0.6.0

## New sensors get their kind's rule automatically
Each kind under *Database → Rules by kind of sensor* now has the switch **Set up new sensors of this kind automatically**. When it is on, a new power sensor gets the power rule (by default 3 days), a new diagnostic value the diagnostics rule, and so on, without a trip through the recommendations.

How it behaves:
- **Only new sensors.** It covers entities created after the switch was turned on. Existing sensors stay in the recommendations as before.
- **After the first analysis that recognises the sensor.** Some kinds depend on how often a sensor reports, so this happens after the daily analysis, not when the entity appears.
- **No minimum size, no immediate purge.** The nightly retention does the deleting. A new sensor has at most a day or two of history at that point.
- **You come first.** Your own settings and dismissals, and use in history-reading helpers, dashboards and the energy dashboard take precedence. Each entity is set up automatically once; afterwards you can change it freely.
- **"Don't record"** needs the package file and takes effect after a restart. Entities without a registry entry are never set up automatically.

Each run shows up in the history as "Rules applied to new sensors".
