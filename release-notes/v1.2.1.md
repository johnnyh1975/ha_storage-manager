# Storage Manager 1.2.1

An independent review of 1.2.0 found three bugs that matter. Please update.

- **Undo now lasts.** If you shortened a history and then pressed Undo, the next scheduled run deleted the restored rows again, because the shorter retention was still set. Undo now puts the retention (or the recording) back as it was. A limit for old long-term statistics waits for your next confirmed run.
- **Deleting events no longer disturbs the recorder.** After deleting an event type that is still recorded, the next such event could fail with a database error, and Home Assistant lost the data it was about to write. Fixed.
- **Only administrators** can run Storage Manager's actions and its cleanup and repack buttons.

Also: applying retention changes always asks first and shows what goes and the safety chain; a full backup that replaces the targeted one checks the free space first; an integrity check that could not run stops deletions; the backup rotation works with a fresh list; and dialogs can be closed with Escape.
