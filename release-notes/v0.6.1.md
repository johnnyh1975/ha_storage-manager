# Storage Manager 0.6.1

- **Settings tab.** The rules by kind of sensor (with the switch for new sensors) and the recorder settings now have their own tab, together with a link to the integration's options (backup rotation, warning thresholds, update interval, backup before deleting). Before, both were collapsed cards at the bottom of the database view. The recommendations in the database view link to the rules.
- **Phones.** The rules stack with the selection below the text, and the active tab scrolls into view.
